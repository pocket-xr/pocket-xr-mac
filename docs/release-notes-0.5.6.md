# Pocket XR for Mac 0.5.6

- **XBX glasses' display is found.** Pocket XR looked for the glasses' display by a maker's name in it: XREAL, NREAL,
  VITURE, ROKID or RAYNEO. The XBX A01+ calls its display "xbx a01+" (seen on Windows), so Pocket XR never found it.
  Now:
  - a display with "XBX" in its name is the glasses;
  - so is a display named the same as the plugged-in glasses' USB product name, whatever the case.

  **Not yet tried with XBX glasses on a Mac**: if the glasses stay blank, use **Send logs to Mike** in the menu.

Everything else is as in 0.5.5.

## Thanks

- **Pierre Zammit**, for logs from his XBX A01+ that showed the display's name.

## Install

Download `PocketXR-Mac-0.5.6.zip`, unzip it and move **Pocket XR** to Applications. One app for Intel and Apple
Silicon, signed with a Developer ID and notarised by Apple.

Pocket XR is a community project, not made by or affiliated with XREAL or VITURE.
