# Pocket XR for Mac 0.4.1

- **VITURE Beast with USB id 35CA:1201** is now recognised as a Beast, like the 35CA:1211 Beast testers have used. A
  tester's Beast on Android reported the 1201 id and was treated as unknown VITURE glasses; the Mac had the same check.
  Not yet tried on a 1201 on a Mac: if you have one, **Send logs to Mike** in the menu helps a lot.

Everything else is as in 0.4.0 (Steady mode's screen gap, Steady mode remembered).

## Install

Download `PocketXR-Mac-0.4.1.zip`, unzip it and move **Pocket XR** to Applications. One app for Intel and Apple
Silicon, signed with a Developer ID and notarised by Apple. Apple Silicon has not been tried on a real M-series Mac
yet.

Pocket XR is a community project, not made by or affiliated with XREAL or VITURE.
