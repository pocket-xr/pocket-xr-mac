# Pocket XR for Mac 0.5.4

- **Readability, for larger and clearer text.** A new switch in Settings, Space, Screens, for any glasses, off by
  default. With it on:
  - you get one screen at 1440 x 810 instead of your usual screens, shown 34 degrees wide and centred;
  - text is larger, and each screen pixel is drawn about one glasses pixel (42 pixels a degree, against 48 for the
    usual 1920 x 1080 screens at 40 degrees).

  Turning it off puts your number of screens, their size and any screens you moved back exactly as they were. The
  layout, distance, curve, Sharper text and where you moved the Space are not touched. Like a change in the number of
  screens, it takes effect when Pocket XR opens again (the **Restart Pocket XR** button shows). **Not yet tried with
  glasses**: if you try it, use **Send logs to Mike** in the menu to say how it looks.

Everything else is as in 0.5.3.

## Thanks

- **Dmitriy**, for the idea and his own version of it (one 1440 x 810 screen at 30 degrees). On a Mac, 30 degrees
  draws text no larger than the usual screens, so Pocket XR uses 34.

## Install

Download `PocketXR-Mac-0.5.4.zip`, unzip it and move **Pocket XR** to Applications. One app for Intel and Apple
Silicon, signed with a Developer ID and notarised by Apple.
